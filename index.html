System requirements & getting started

Requirements: Linux (amd64) or Windows 10/11 · ~600 MB disk · 4 GB RAM recommended · the app is fully offline after install.

First run: Install the .deb (Linux) or run the .exe (Windows), launch KitchenOS, create a local user — your data lives in a local SQLite file. To try Premium later, use the Billing page to open the Premium web app.
